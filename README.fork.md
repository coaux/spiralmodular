# The (Unofficial) Fork of Spiral Synth Modular

GitHub: https://github.com/coaux/spiralmodular/

## Installation

### Build Dependencies

For Fedora 44 platforms
- `cmake`
- `bintuils`
- C++ compiler supporting C++23
- `pkgconf-pkg-config`
- `fltk-devel`
- `pulseaudio-utils`, providing `libpulsedsp.so`
- `argparse-devel`
- `boost-devel`
- `boost-filesystem`

Optional (Fedora 44)
- libsndfile-devel
- alsa-lib-devel
- ladspa-devel, liblrdf-devel
- one of:
    - jack-audio-connection-kit-devel
    - pipewire-jack-audio-connection-kit-devel
